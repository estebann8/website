# Personal website starter

A plain HTML/CSS/JS site — no build tools, no dependencies. Open
`index.html` in a browser, or use VS Code's Live Server extension to
preview with auto-reload.

## Files

- `index.html` — content and structure
- `styles.css` — colors, type, and layout (see the tokens at the top)
- `script.js` — mobile menu toggle + auto-updating footer year

## Making it yours

In `index.html`, replace:
- The `<title>` and meta description
- "Maya Chen" in the header and footer
- The hero heading and intro paragraph
- The About section text
- The Work list — swap in your own projects or delete items
- The email address and social links

In `styles.css`, the `:root` block at the top holds the colors and
fonts — change `--teal` and `--ochre` to your own accent colors.

## Publishing it with GitHub Pages

See the setup steps your assistant walked you through for creating the
repo and pushing this code. Once it's on GitHub:

1. On the repo page, go to **Settings → Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
3. GitHub gives you a URL like `https://yourusername.github.io/repo-name`
   within a minute or two.
